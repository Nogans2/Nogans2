# Штендер «Модульный диван TOM» (KF.8333 / 90.BY.736), 80×160 см

Исходник `stand.html` (800×1600 px = мм), сборка — скрипты из `../tim/tools/` (render.js, pdf.js).

## Рисовка схем (вид сверху, по фото из салона)
- Платформа сиденья со скруглёнными углами, стёжка КЛЕТКАМИ (не кружками!): швы-впадины линиями (светлая полоса 4 + тонкая линия), точка-углубление на каждом пересечении. Швы по фабричному чертежу: у подлокотника узкая колонка 30 см под валиком, дальше колонки ≈43 см на диванах (≈54 на угловом, шезлонге, пуфе — 2 колонки), вертикальные швы через всю глубину. Ряды дивана 27/36/37% глубины; шезлонг — ряды по ≈40 см.
- Подушки спинки — отдельные, 84 см, толщина 27, слегка вогнутый передний край, с промежутками; у углового модуля две по 74 см (Г).
- Подлокотники — валики 22 см, лежат на платформе, длина = глубина − 9.
- Шезлонг: стёжка + одна подушка 84 вдоль края. Пуф: только стёжка.
- Функция `piece()` + `cush()` в `stand.html`; `rot:1` — повернуть модуль на 90°.

## Данные
Модули (глубина 108, 6 в ряд): 2,5 с двумя подл. 207 · 3,5 с двумя подл. 236 · 3,5 с подл. 204 · 1,5 без подл. 88 · угловой 108×108 (спинки 74 угол об угол) · шезлонг CL 108×161. Пуфа нет. У 2,5 швы как у 3,5 (4 клетки, cols:4). Иконки: 4 шт., без «Мягкости». Внизу — фото дивана на белом фоне (sofa_white.jpg).
Комбинации по эскизам салона: C1 3,5+угл+шезлонг 312×269 · C2 3,5+1,5+угл+шезлонг 400×269 · C3 3,5+угл+3,5 312×312 · C4 3,5+1,5+угл+3,5 400×312 · C5 3,5+шезлонг CL повёрнут вдоль, подушка у спинки со стороны дивана 365×108 · C6 два 3,5 408×108.
