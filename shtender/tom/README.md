# Штендер «Модульный диван TOM» (KF.8333 / 90.BY.736), 80×160 см

Исходник `stand.html` (800×1600 px = мм), сборка — скрипты из `../tim/tools/` (render.js, pdf.js).

## Рисовка схем (вид сверху, по фото из салона)
- Платформа сиденья со скруглёнными углами, стёжка КЛЕТКАМИ (не кружками!): швы-впадины линиями (светлая полоса 4 + тонкая линия), точка-углубление на каждом пересечении. Ряды 27% / 36,5% / 36,5% глубины, колонки ≈ 52 см.
- Подушки спинки — отдельные, 84 см, толщина 27, слегка вогнутый передний край, с промежутками; у углового модуля две по 74 см (Г).
- Подлокотники — валики 22 см, лежат на платформе, длина = глубина − 9.
- Шезлонг: стёжка + одна подушка 84 вдоль края. Пуф: только стёжка.
- Функция `piece()` + `cush()` в `stand.html`; `rot:1` — повернуть модуль на 90°.

## Данные
Модули (глубина 108): 2,5 с двумя подл. 207 · 3,5 с двумя подл. 236 · 3,5 с подл. 204 (215 с поднятым) · 1,5 без подл. 88 · угловой 108×108 · шезлонг 108×161 · пуф 108×108.
Комбинации: C1 400×269 (схема фабрики) · C2 312×312 · C3 312×161 · C4 496×108 · C5 322×100 · C6 392×260 (C5, C6 — из каталога KUKA, глубина 100).
Открыто: глубина 100 (каталог) или 108 (техлист); нужны ли C2–C4.
