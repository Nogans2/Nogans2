# Штендер «Модульный диван TIM» (80×160 см)

Финальный макет: `Tim_shtender_FINAL_80x160.pdf`, превью: `Tim_shtender_FINAL_preview.png`.
Исходник: `stand.html` (холст 800×1600 px = 1 px на 1 мм).

## Как пересобрать

```bash
node tools/render.js "$PWD/stand.html" "$PWD/preview.png"
node tools/pdf.js "$PWD/stand.html" "$PWD/Tim_shtender_80x160.pdf"
```

PDF: страница 800×1600 мм, `html{zoom:3.7795}` (1 мм в CSS-пикселях). Нужен Playwright + Chromium.

## Образцы дерева — как нарисованы

Векторные SVG-квадратики 36×36, генерируются `tools/wood_swatch.py`:

1. базовая заливка цветом дерева;
2. широкие тональные полосы — вертикальные кривые Безье (ширина 2–6, светлее/темнее, прозрачность 0.35–0.7);
3. тонкие волокна — кривые толщиной 0.25–0.6 тёмным цветом, шаг 1.4–3.2, лёгкий изгиб;
4. блик — диагональный градиент (белый 28% → прозрачный → чёрный 15%), эффект лака;
5. рамка 1px чуть темнее основного цвета, скругление 6.

Случайность с фиксированным seed (`Random(7+idx)`), поэтому рисунок не меняется между сборками.
Цвета: натуральный `#dcbb92`, коричневый 787 `#8a5a3b`, тёмный L016 `#382923`.
Важно: тонкие CSS-полосы (repeating-linear-gradient) выглядят «лесенкой» — для образцов использовать только SVG-кривые.

## Правила, согласованные с салоном

- Тон — на «ты» («Собери свой», «спроси у консультанта»).
- Цен нет. Пометок «Л/П» нет.
- Порядок блоков: заголовок TIM → характеристики → «Популярные комбинации» (C1–C7) → плашка с деревом → модули → полоса с логотипами.
- Деревянные подлокотники — только общей плашкой с фото и тремя образцами цвета, не на схемах.
- Схемы — вид сверху; ширина линией сверху, глубина линией сбоку. Подлокотники короче глубины (у дивана −20 см, у шезлонга −45 см).
- Все глубины/боковые размеры округлены до 115.
- Логотипы внизу на светлой полосе: SG-кружок + southgate фирменным шрифтом (`sg_logo.png`), Ashley — `ashley_logo.png`.
- Шрифт макета — Montserrat (`fonts/`).
