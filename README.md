# Пакт — дисциплина на двоих

Приложение для iPhone (и Android) для пары: каждый день одни и те же задания, отмечаешь галочкой то, что сделал.

- **Два профиля** — его и её. Каждый заходит в свой, телефон запоминает выбор.
- **Галочка = выполнено.** Задание без галочки к 00:00 считается пропуском: **−100** монет.
- **Каждый месяц счёт с нуля.** 1-го числа баланс обнуляется, итог прошлого месяца остаётся в истории.
- Вчерашний день можно исправить до 12:00 (если забыл поставить галочку).
- Календарь месяца, серия дней без пропусков, статистика по каждому заданию.
- Задания можно добавлять, переименовывать, менять иконку и время, удалять.
- Работает без интернета после первого открытия.

Задания по умолчанию:

| Он | Она |
| --- | --- |
| 💊 Выпить креатин | 💊 Выпить витамины |
| 🏋️ Сходить в зал | 🧘‍♀️ Сходить на пилатес |
| 🌙 Лечь спать до 00:00 | 🌙 Лечь спать до 00:00 |

## Как поставить на iPhone

1. **Один раз включить сайт на GitHub** (это бесплатно):
   откройте репозиторий на github.com → **Settings** → **Pages** →
   в «Build and deployment» выберите **Deploy from a branch** →
   ветка **`claude/mobile-app-w4i9zu`**, папка **`/ (root)`** → **Save**.
   Через минуту-две приложение будет доступно по адресу
   **https://nogans2.github.io/Nogans2/**
2. Откройте эту ссылку на iPhone в **Safari**.
3. Нажмите **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** → **«Добавить»**.
4. На экране появится иконка «Пакт». Откройте её и выберите свой профиль.

Девушка делает то же самое на своём телефоне и выбирает свой профиль.

## Где хранятся данные

Галочки хранятся на самом телефоне. Ссылка одна для обоих, но каждый телефон хранит
свои отметки. Чтобы не потерять данные (например, при удалении приложения с экрана «Домой»),
в разделе **«Профиль» → «Данные»** можно скопировать резервную копию и потом вернуть её.

## Файлы

- `index.html` — всё приложение (интерфейс и логика).
- `manifest.webmanifest`, `icons/` — иконка и настройки для установки на экран «Домой».
- `sw.js` — офлайн-режим.

# Планер — задачи, привычки, режим дня, бюджет

Второе приложение лежит в папке `planner/`. Чтобы оно открылось по адресу
**https://nogans2.github.io/Nogans2/planner/**, в **Settings → Pages** выберите ветку
**`claude/blissful-faraday-e0heo0`** (в ней есть и «Пакт», и Планер — данные «Пакта» на телефоне не пропадут).

- **Обзор** — эффективность за сегодня (привычки + режим дня + задачи на сегодня), график по дням месяца, серия дней ≥ 80%, ближайшие задачи, режим на сегодня.
- **Задачи** — срок, сколько дней осталось, приоритет (Срочно / Высокий / Средний / Низкий), категории, фильтры.
- **Привычки** — таблица месяца с галочками по дням и неделям, «выполнено / не выполнено / прогресс %» за каждый день, % по каждой привычке, плюс еженедельные и ежемесячные привычки.
- **Режим дня** — своё расписание на каждый день недели, отмечаешь выполненные блоки, можно скопировать день в другие.
- **Бюджет** — доходы, подписки, регулярные платежи, траты, накопления, долги: бюджет и факт, графики «бюджет vs факт» и «куда ушли деньги». Новый месяц берёт статьи из прошлого.
- **Данные** (кнопка на «Обзоре») — резервная копия, восстановление, светлая/тёмная тема.

Ставится на iPhone так же: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
Данные хранятся на телефоне, отдельно от «Пакта».

### Задачи из чата с Claude

Claude присылает ссылку вида
`https://nogans2.github.io/Nogans2/planner/?add=Позвонить поставщику&due=2026-11-20&prio=1&cat=Работа`.

- Если Планер открыт в Safari — просто нажмите на ссылку.
- Если Планер установлен на экран «Домой» — скопируйте ссылку и вставьте её в поле «Новая задача» на вкладке «Задачи» (у иконки на экране «Домой» своя память, отдельная от Safari).

`prio`: 0 Срочно, 1 Высокий, 2 Средний, 3 Низкий. Несколько задач: `add=Задача|2026-11-20|1|Работа&add=…`. Одна и та же ссылка дважды не добавляется.

### Синхронизация задач с Google Таблицей («Джарвис»)

Задачи Планера связаны с таблицей «Планер — входящие» через Apps Script, её видит и меняет голосовой ассистент «Джарвис».

- При открытии Планера (и когда возвращаешься в него) сначала отправляются неотправленные изменения, потом из таблицы забираются новые задачи и правки Джарвиса. Задачи, которых в таблице нет, из Планера не удаляются. После этого в таблицу уходит весь итоговый список.
- После любого изменения задач в Планере (добавил, изменил, выполнил, удалил) весь список сразу уходит в таблицу. Нет интернета — отправится при следующем открытии.
